Scaffold4D

4D-Scaffold-GS → 稀疏 4D 锚点(冻结)+ 32 维特征 + 三个共享 MLP 生成 K=10 个子椭球,恒定速度运动,广义高斯时间门(β=4);分支 codex/scaffold4d-esvr

共同配方(除非表中注明)

训练
120,000 步;每步随机 1 帧 + 随机 64³ 块(tile 采样);损失 0.8·L1 + 0.2·(1−SSIM) + 0.01·mean(∏scale)
优化器
4D-Scaffold-GS 原生 7 组:anchor 0(冻结)、offset 0.01→1e-4、log_offset_scale 0.007、feature 0.0075、opacity-MLP 0.002→2e-5、shape-MLP 0.004、flow-MLP 0.001;Adam eps 1e-15,不裁剪
锚点生长
上游算法移植:统计 ‖∂L/∂xyz‖·opacity_t·σ^γ(γ=1,ESVR 的 3D 中心梯度替代 2D 屏幕梯度),窗口 1,500–60,000 每 100 步,三级 4D 格子 16/4/1 体素 × 1 帧,只在空格子中心新建,特征 max-pool;阈值按实测梯度 p90 校准(修复核 1.2e-3;未修复核时 4e-7)
ESVR 适配项
子椭球尺度下限 0.5 体素;opacity 头 sigmoid(上游 tanh+掩码会在零特征初始化下全部死亡);时间截断 1e-3;σ/offset 数值钳位;锚点数上限(上游无)
初始化
6,000 锚点均匀随机(空间 + 时间),尺度取最近邻距离;子椭球初始幅值 sigmoid(0)=0.5;速度上限 tanh 原生 1
锚点 / 高斯列
锚点 = 训练结束时的锚点数;高斯 = 锚点 × K,即模型能生成的子椭球总数(每个锚点固定生成 K 个,多余的靠压小/压暗关闭);活跃/查询 = 训练末段每步渲染时通过时间门(opacity > 1e-3)被送入 CUDA 的子椭球数;有用/查询 t=0.5 = 其中强度 > 1/255 且尺度未贴在 0.5 体素下限的,在序列中点 t = 0.5 这一个时刻切片统计;有用/查询 90 帧均值 = 同一条件在全部 90 个训练时刻各切一次后的均值(括号内为最小–最大);有用总数 = 全体子椭球中满足同一条件的数量及占比(与时间无关);90 帧从未选入 = 在全部 90 个训练时刻都没有通过时间门(home 时刻漂出 [0,1] 或时间窗落在两帧之间)的子椭球,它们对这 90 帧的重建零贡献、可精确删除;“其中有用”是这些里按强度/尺度本来算“有用”的数量——修复核的运行里只有 ~1%,说明“有用总数”几乎没有被时间上死掉的高斯抬高。对照:静态单帧 ESVR(修复核、正确配方)21k 基元 / 22k 步 = 41.7 dB,16k 基元 / 67k 步 = 44.7 dB,139k 基元 / 67k 步 = 49.7 dB(A 节 S 系列)

实现与上游的对应与偏离(审计 2026-09-22)

基元、核、监督来自 ESVR;锚点/特征/子椭球结构、线性运动、广义高斯时间门、7 组优化器、dynamic-aware 生长来自 4D-Scaffold-GS 官方代码。不是逐行等价移植;每一处偏离及其实测影响如下(详见 docs/ESVR_SCAFFOLD4D.md)
偏离上游之处原因实测
opacity 头用 sigmoid,而非 tanh + “>0 掩码”tanh + 零特征初始化在 ~50 步内让全部孩子转负、永久死亡没有它无法训练
上游 min_opacity 锚点剪枝几乎不触发K 个 sigmoid 强度之和很少低于每次 0.005;上游 tanh 给出精确的 0每次运行只删 1–70 个;--prune-dead(ESVR 的 prune_zeros / 暗剪枝)能回收但不改变 PSNR(D.4)
生长统计用 3D 中心梯度代替 2D 屏幕梯度没有相机;这是 ESVR 自己 add_densification_stats 的量阈值按 3D 梯度 p90 校准(修复核 1.2e-3)
“观测足够”判据按块占体积比例缩放孩子只在其 64³ 块被采到时才被观测—
锚点数上限 + 按投票强度排序准入上游无上限40k / 100k / 150k / 300k 均已测
所有格子层级每轮都执行(--grow-upstream-level-skip 恢复上游规则)上游只在粗层级本轮长出锚点时才执行细层级;09-22 审计才发现未测
锚点时间均匀随机初始化(上游全在 t₀)体数据没有 SfM 帧--init data(按 GT 采样)vs 随机:0.0 dB
子尺度 0.5 体素下限;σ ∈ [1e-2, 1e2];offset ∈ [−10, 10]float32 / CUDA 失效模式(NaN、亚体素孩子零梯度)下限:去掉 −3.3 dB
时间截断 1e-3效率;低于核的 1/255—
体积正则作用于全部时间激活的孩子(上游作用于被渲染的)mini-batch 数据项 + 全局正则只作用可见孩子 0.0 dB;去掉 −0.6 dB
--final-lr-scale 0.01(ESVR 配方,非默认)上游恒定的 4 组学习率在块监督下后期震荡 ±0.7 dB;ESVR 自身学习率也衰减150k 锚点 +5 dB;默认保持 1.0 使 argparse 默认 = 论文值
每帧优化预算约为静态 ESVR 的 1/1290 帧共享一次训练静态天花板研究(A 节)
逐段核对结论(代码 vs generate_neural_gaussians / training_statis / anchor_growing / adjust_anchor / train.py,以及 ESVR 的 train_chunk.py / gaussian_model.py / forward.cu):4D home 位置、线性运动、时间门(β=4)、时不变尺度旋转、7 组学习率与 expon_lr、增密统计权重、三层级格子生长、特征 max-pool、Adam eps、损失三项、SSIM(= 各 x 切片 2D SSIM 均值,与 ESVR 相同)、块坐标约定、评估口径(预测本在 [0,1] 内,裁剪 Δ=0)均一致;CUDA 位置梯度经有限差分验证(比值 1.00);G5/H4/I3 重载逐字节一致;压缩文件可被 inference_scaffold4d.py 读取并复现(H4 第 46 帧 39.34 vs 39.34 dB)。

独立审阅(2026-09-22,另一个不带本会话先验的代理逐行对照上游代码):未发现影响任何已报数字的错误;它用单体素定位验证了块坐标约定与分块评估逐位一致,核对了扁平索引记账、优化器状态切片、生长/剪枝与上游的逐项对应、expon_lr、压缩位掩码往返、数据轴序与时间归一化。提出的 9 项健壮性/文档问题(缺失参数被 strict=False 掩盖、--grow-depth 4 格子尺寸为 0、--init data 的最近邻只用 xyz 且 N²、时间门测试靠浮点下溢通过、文档数字漂移等)已全部修复并提交。本页的每一行结果数字都经过重新计算,来源仅为各运行的完整 90 帧 evaluation/metrics.json。
关于“无用高斯”与模型大小(2026-09-22):这是表征层面的结构性现象,不是生长/剪枝代码的错误。每个锚点固定生成 K=10 个孩子,不需要的孩子只能被优化器“关掉”——上游用 tanh 掩码免费关闭(但其 offset 同样占存储,上游论文报的 storage 也包含全部 K 个 offset);在 ESVR 的加法渲染下只能压暗/压小,结果相同:存储里 60–90% 是死孩子。训练时删掉它们的两种途径都已测过:死锚点回收(T2)让新生锚点以同样速度死去,有用率不变;上游 min_opacity 在 sigmoid 下失效。有效的做法是训练后压缩(精确删暗孩子 + 位掩码 + fp16,6–7×,PSNR 不变),以及用更小的锚点上限换更长训练(J1:40k 锚点 / 480k 步 = 36.9 dB,压缩后 2.6 MB)。“压缩前就小”的路线正在 K4(60k 上限 + 回收,480k 步)中测试。
