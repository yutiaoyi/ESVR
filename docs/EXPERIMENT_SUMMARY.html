锚点 / 高斯列
锚点 = 训练结束时的锚点数;高斯 = 锚点 × K,即模型能生成的子椭球总数(每个锚点固定生成 K 个,多余的靠压小/压暗关闭);活跃/查询 = 训练末段每步渲染时通过时间门(opacity > 1e-3)被送入 CUDA 的子椭球数;有用/查询 t=0.5 = 其中强度 > 1/255 且尺度未贴在 0.5 体素下限的,在序列中点 t = 0.5 这一个时刻切片统计;有用/查询 90 帧均值 = 同一条件在全部 90 个训练时刻各切一次后的均值(括号内为最小–最大);有用总数 = 全体子椭球中满足同一条件的数量及占比(与时间无关);90 帧从未选入 = 在全部 90 个训练时刻都没有通过时间门(home 时刻漂出 [0,1] 或时间窗落在两帧之间)的子椭球,它们对这 90 帧的重建零贡献、可精确删除;“其中有用”是这些里按强度/尺度本来算“有用”的数量——修复核的 90 帧运行里只有 ~1%,说明“有用总数”几乎没有被时间上死掉的高斯抬高(例外是只训 10 帧的 K1:随机 t 初始化让 61% 的孩子落在没训过的时刻,其中 6.3 万“有用”);任一时刻起作用 = 有用 且 至少在一个训练时刻被选入,即真正参与过重建的子椭球数及占比;全程无用 = 其余全部(太暗 / 贴尺度下限 / 从未选入),这两个数相加等于“高斯”总数。“有用/查询”与“任一时刻起作用”之差反映跨时刻复用的程度。对照:静态单帧 ESVR(修复核、正确配方)21k 基元 / 22k 步 = 41.7 dB,16k 基元 / 67k 步 = 44.7 dB,139k 基元 / 67k 步 = 49.7 dB(A 节 S 系列)

块大小(P1 / P1b):每步成本几乎与块大小无关(64³ 30 ms、128³ 51 ms,且独占 GPU 时更接近),所以整体积监督每步多 8 倍监督量几乎免费;唯一的陷阱是生长阈值不能沿用 64³ 的校准值。P1b 以一半步数、0.75 小时、29 MB 训练大小拿到 40.17 dB,是目前的新基准。K2(D.8)的“整体积监督更差”结论作废(等体素数的对照 + 未校准阈值)。另一个观察:时间门在 53k 步时中位半宽还有 12–30 帧,480k 步才收到 3.5 帧——σ 学得慢,MLP 学习率 ×3 略正可能与此有关。
